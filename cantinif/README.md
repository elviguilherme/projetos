# CantinIF – Pedido antecipado na cantina

Projeto em grupo (4 alunos) da disciplina de Engenharia de Software do curso Técnico em Desenvolvimento de Sistemas – IFTM, em 2026. O objetivo é permitir que alunos peçam o lanche pelo aplicativo, paguem por PIX e retirem no balcão com uma senha, sem filas.

Atuei como **Product Owner**: levantamento de requisitos com stakeholders e especificação de requisitos funcionais e não funcionais.
