## Como adicionar um projeto novo

1. Crie uma pasta com o nome do projeto, em minúsculas e com hífens (exemplo: `meu-projeto`).
2. Coloque os arquivos dentro dela, com um `README.md` explicando o projeto.
3. Acrescente uma linha na tabela acima e um link na página `index.html`.
