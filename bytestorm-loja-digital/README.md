# ByteStorm – Loja Digital

Site de uma loja fictícia de hardware e tecnologia, com vitrine de produtos e uma página de detalhes para cada item. Feito com HTML e CSS.

Trabalho do curso Técnico em Desenvolvimento de Sistemas – IFTM Campus Uberaba Parque Tecnológico.

**Site publicado:** https://site-loja-digital.netlify.app/

## Funcionalidades

- Página inicial com vitrine de 8 produtos
- Página de detalhes para cada produto, com estilo próprio
- Navegação entre a vitrine e as páginas de produto

## Tecnologias

- HTML5
- CSS3
- Netlify (hospedagem)

## Como executar

Acesse o site publicado ou baixe o repositório e abra o arquivo `index.html` no navegador.
