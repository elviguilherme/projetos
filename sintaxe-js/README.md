# Sintaxe JavaScript

Este repositório servirá como guia de aprendizagem em **JavaScript**. Execute os arquivos `index.html` de cada diretório para visualizar o comportamento do código em **JS**. Abra também o *console* no navegador para visualizar  a saída do programa.
