# WebApp – Cadastro de Livros

Aplicação web para cadastrar livros com título, autor e capa, feita com HTML, CSS e JavaScript puro.

Trabalho da disciplina de Front-end (FWII) do curso Técnico em Desenvolvimento de Sistemas – IFTM Campus Uberaba Parque Tecnológico.

## Funcionalidades

- Cadastro de livros com título, autor e link da imagem da capa
- Validação do formulário: todos os campos são obrigatórios
- Exibição dos livros em cartões com a capa
- Imagem reserva quando o link da capa não carrega
- Remoção de livros da lista

## Tecnologias

- HTML5
- CSS3
- JavaScript (manipulação do DOM e eventos)

## Como executar

Baixe o repositório e abra o arquivo `index.html` no navegador.
